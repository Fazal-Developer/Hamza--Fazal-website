YogaFlow

Daily Wellness & Guided Yoga Routine App

YogaFlow is a fitness companion mobile app designed to help users establish consistent yoga habits. It features step-by-step pose guides, customizable workout timers, and habit streak tracking.

View GitHub Code
The Problem

Challenge Overview

Beginners find yoga routines intimidating without structured pose guides and timer cues.

The Solution

Engineering Approach

Built a clean mobile app featuring visual pose tutorials, audio cues, and daily streak tracking.

/ TECHNICAL BREAKDOWN

Key Features & Architecture

Core Features Checklist:

  • Beginner, Intermediate & Advanced pose libraries
  • Customizable workout timer with audio transition chimes
  • Daily habit streak calendar & progress stats
  • Smooth animations and soothing Material UI aesthetic
Software Architecture Pattern

MVVM architecture with Custom Timer Handlers and Local Storage.

Technical Challenges Overcome

Creating fluid, non-jarring timer countdown transitions.

Key Developer Learnings

Improved expertise in Android animation frameworks and custom layout components.
